# Acceptance Checklist

## Formal project
- [ ] `lake build` succeeds in a clean environment.
- [ ] No unresolved `sorry` in proof modules.
- [ ] No undocumented axioms.
- [ ] Theorem statements match intended contracts.
- [ ] Hard constraints are immutable within the revision interface.

## Scientific integrity
- [ ] Every biological statement has a traceable source.
- [ ] Every parameter has units, context, uncertainty, and provenance.
- [ ] Species and tissue differences are explicit.
- [ ] Verification is not described as validation.
- [ ] Model admissibility is not described as biological safety.

## Governance
- [ ] No automated change to mandatory constraints.
- [ ] Human review is retained.
- [ ] Research use has institutional and regulatory oversight.
